# Literature (`lit/`)

Annotated bibliography for the program. One markdown file per paper, named `YYYY-shortkey.md` (e.g. `2024-trm.md`). Use [TEMPLATE.md](TEMPLATE.md) for each note. Keep `index.md` as the master list grouped by pillar.

## Pillars

1. Limits of transformers / next-token objective (scaling vs reasoning).
2. Memory & long context (SSMs, recurrence, external/episodic memory).
3. World models / latent prediction (JEPA, energy-based models).
4. ARC corpus (reports, surveys, neurosymbolic, program synthesis, TTT, MDL).
5. Algorithms & information theory (Knuth TAOCP, Kolmogorov complexity / MDL).
6. Cognitive science of fluid intelligence (Chollet, few-shot abstraction).

A reading note is "done" when it answers: what problem, what mechanism, what evidence, what it costs, and which `ledger/limitations.md` item it speaks to.
